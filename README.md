# Small-business-lan
A small business LAN built Cisco Packet Tracer to practice IPv4 addressing, default gateways, and network connectivity.

Small Business LAN — Cisco Packet Tracer
Project Overview
This project demonstrates the configuration and testing of a small business Local Area Network (LAN) using Cisco Packet Tracer.

Network Setup
1 Router
1 Switch
3 PCs
Skills Demonstrated
IPv4 addressing
Default gateway configuration
Basic LAN connectivity
Network troubleshooting using ping
Network topology design
IP Addressing
Device

IP Address

PC0

192.168.1.10

PC1

192.168.1.11

Connectivity Testing
Used the ping command to verify connectivity between PCs on the network.

Tools Used
Cisco Packet Tracer
GitHub
Project Purpose
To strengthen networking fundamentals and develop practical skills relevant to entry-level IT support, help desk, and networking roles while preparing for the CCNA.
